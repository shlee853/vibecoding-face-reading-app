# PRD: 관상사주 분석 AI 웹앱

## 1. 한 줄 요약
사용자가 사진을 업로드하면 AI가 관상을 분석해 주고 사주와 연관지어 해석해 주는 대중적인 웹 서비스.

## 2. 배경과 문제
- **배경**: 관상과 사주에 대한 대중의 호기심은 높지만, 전문 점쟁이 방문이 부담스럽거나 비용이 들 수 있음
- **문제**: 온라인에서 쉽고 빠르게 관상 분석을 받고 싶은 일반인들
- **기회**: AI를 활용해 즉시 분석 결과를 제공하는 재미있는 서비스

## 3. 목표와 비목표

### 목표
- 사진 업로드로 관상을 AI가 즉시 분석해 줌
- 분석 결과에 사주 연관 해석 포함
- 빠른 응답 속도와 직관적인 UI로 사용자 경험 최적화
- MVP 출시 후 반복적으로 개선할 수 있는 구조

### 비목표 (이번에 하지 않는 것)
- 사용자 계정/로그인 (MVP 단계)
- 결과 저장/공유 기능 (향후)
- 카메라 촬영 기능 (MVP는 사진 업로드만)
- 결과 커스터마이징/재분석 기능
- 다국어 지원 (한국어 우선)

## 4. 대상 사용자
- 관상과 사주에 관심 있는 일반인 (주로 20~50대)
- 재미와 호기심으로 접근
- 모바일/웹 모두 편하게 접근 가능한 사람들

## 5. 핵심 시나리오 (사용자 여정)
1. 웹사이트 방문
2. "사진 선택" 버튼 클릭
3. 자신의 얼굴 사진 업로드
4. AI가 관상 분석 중... (로딩 화면)
5. 관상 분석 결과 표시 (주요 특징, 성격 해석, 운세 연관)
6. 결과 읽기 (카카오톡 공유 등은 나중에)

## 6. 기능 요구사항

### [P0] 반드시 필요
- **사진 업로드**: 로컬 파일 선택 및 미리보기
- **관상 분석**: Gemini Pro 2.0 API로 얼굴 이미지 분석
  - 얼굴 특징 감지 (이마, 눈, 코, 입, 턱 등)
  - 각 부위별 관상 해석 (성격, 운세, 길흉)
- **사주 연관 분석**: 관상 결과를 바탕으로 사주 운과 연결지은 해석 추가
- **결과 화면**: 깔끔한 UI로 분석 결과 표시
  - 분석된 얼굴 특징
  - 관상 해석 (단락별)
  - 사주 연관 운세

### [P1] 있으면 좋음
- 결과 다시 보기 (임시 저장)
- 기본적인 오류 처리 (이미지 미업로드, 얼굴 미인식 등)

### [P2] 향후 추가
- 사진 저장/공유 기능
- 카메라 촬영 기능
- 사용자 계정 및 히스토리
- 사주 생년월일 입력으로 상세 분석

## 7. 비기능 요구사항
- **성능**: 사진 업로드 후 분석 완료까지 5초 이내 (AI 응답 포함)
- **응답성**: 모바일(375px 이상)에서도 빠르고 쾌적한 경험
- **가용성**: 기본적인 에러 처리로 서비스 중단 최소화
- **규모**: MVP 단계 (동시 사용자 100명 수준 고려)

## 8. 연동 및 의존성
- **Gemini Pro 2.0 API**: 이미지 분석 및 텍스트 생성
- **사용자 제공 API 키**: 개발 초기 단계에서 API 비용 관리
- **호스팅**: Vercel 또는 유사 플랫폼 (나중)

## 9. 성공 지표
- MVP 출시 가능 (기본 기능 동작)
- 사진 업로드 후 분석 결과까지 평균 5초 이내
- 사용자 피드백 수집 (분석 정확도, UI/UX 개선점)

## 10. 가정과 열린 질문
- **가정**: Gemini Pro가 충분히 정확한 관상 분석 능력을 가지고 있음
- **열린 질문**:
  - 얼굴 인식 실패 시 사용자에게 어떻게 안내할 건가?
  - 관상 + 사주 연관 해석의 정확도를 어느 수준까지 보장할 건가? (재미 vs 신뢰도)

## 11. 범위 밖 / 향후 과제
- 카메라 촬영 기능 (Sprint 2)
- 사용자 계정 및 로그인 (Sprint 3)
- 결과 저장 및 공유 (Sprint 3)
- 사주 생년월일 기반 상세 분석 (Sprint 3)
- 다국어 지원 (향후)
